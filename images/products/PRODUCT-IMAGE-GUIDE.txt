WHERE THE IMAGES GO
-------------------
Drop all product photos into this folder:
    images/products/

HOW IT WORKS
------------
- Each card on men.html and women.html already has an <img> that points
  to one of the file names listed below.
- Until you add a file, the card shows the "Image Coming Soon" placeholder
  (images/products/placeholder.svg) automatically — nothing looks broken.
- As soon as you add a correctly-named file, that card shows your photo.
  No code changes needed.

FILE NAMING RULES  (IMPORTANT)
------------------------------
- Names must match EXACTLY, including the number and the .jpg extension.
      e.g.  men-01.jpg   women-13.jpg
- Numbers are two digits: 01, 02, ... not 1, 2.
- If your photo is .png or .webp instead of .jpg, either:
      (a) rename the file to .jpg, OR
      (b) open the page and change the src extension in that card.
- Best shape: portrait, 4:5 ratio (e.g. 800 x 1000 px). Photos are
  auto-cropped to fit, so a portrait image looks best.
