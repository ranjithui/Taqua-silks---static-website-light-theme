# Add Your Saree Images Here

Save your photos in **this folder** (`images/photos/`) using the file names below.
Each one switches into the live site automatically — **no code changes needed**.

**Any format works.** The loader tries `.jpg`, `.png`, `.webp`, `.jpeg` and `.avif` for every
name, so `drape-07.png` or `drape-07.webp` is found automatically. The tables write `.jpg`
only as shorthand for "the `drape-07` slot". Only the **file name** has to match.

Until a file exists, an elegant **woven-silk placeholder** (gold motif on royal violet) shows
in its place, so the site never looks broken while you gather images.

Recommended: **vertical 4:5**, plain warm background, soft even lighting.

## Licensing — please read

Only use images you own or have licensed for **commercial** use:

- **Your own studio photos** — best option, and they show real stock.
- **Paid stock** (Shutterstock, Adobe Stock) — fine once licensed in your name. Do not use
  watermarked search previews.
- **Free stock** (Pexels, Unsplash) — licences permit commercial use without attribution.
- ❌ Do **not** copy product photos from other retailers' websites.
- ⚠️ A Creative Commons licence covers the photographer's copyright but **not a model
  release**. Photos of identifiable people — especially children — need a release before
  they can be used in advertising.
